                                                          Project Summary Report
                                        Analysing E-Learning Platform Purchases using MySQL
1. Project Objective

The objective of this project is to analyse e-learning platform purchase data using MySQL. The analysis focuses on learner purchasing behaviour, course popularity, category-wise revenue and sales performance.

2. Database Description

The project uses three relational tables:
•	Learners: Stores learner names and countries.
•	Courses: Stores course names, categories and unit prices.
•	Purchases: Stores learner purchases, quantities and purchase dates.

3. Key Insights
   
1.	Aisha recorded the highest total spending of 8,500.
2.	SQL Basics is the most purchased course, with 6 units sold.
3.	Data Analytics generated the highest revenue of 17,700.
4.	Priya and Aisha purchased courses from more than one category.
5.	Digital Marketing has not received any purchases.

4. Recommendations
   
•	Focus marketing activities on popular courses such as SQL Basics.

•	Promote Data Analytics courses to increase revenue.

•	Provide special offers for courses with zero purchases.

•	Encourage learners to explore multiple course categories.

•	Monitor learner purchasing behaviour to improve sales performance.

6. Conclusion
   
This project demonstrates how MySQL can be used to manage relational databases and analyse e-learning purchase data. By using SQL joins, aggregate functions, filtering and analytical queries, meaningful business insights can be generated to support management decisions.
